# 图片分享社区

基于微信小程序云开发的图片分享应用，包含首页、个人主页、图片详情和上传历史页。

## 云端配置

1. 创建 `photos` 集合。
2. 将集合权限设为“所有用户可读，仅创建者及管理员可写”。
3. 上传并部署 `cloudfunctions/getOpenid`，选择“云端安装依赖”。
4. 为 `photos` 集合创建联合索引：`tag` 升序、`createdAt` 降序，用于首页标签筛选和上传时间排序。
5. 如果云开发控制台提示个人作品查询缺少索引，再创建 `_openid` 升序、`createdAt` 降序的联合索引。

## photos 字段

| 字段 | 说明 |
| --- | --- |
| `photoUrl` | 云存储文件 ID |
| `avatarUrl` | 作者头像 |
| `nickName` | 作者昵称 |
| `tag` | 图片标签，如风景、人像、日常、校园、萌宠等 |
| `addDate` | 上传日期，格式为 `YYYY-MM-DD` |
| `createdAt` | 云端创建时间 |
| `_openid` | 云数据库自动记录的用户 OpenID |

## 功能

- 首页、上传历史和个人主页均按实际上传时间倒序展示，最新图片置顶；首页支持按标签筛选。
- 底部导航可切换首页、上传图片和个人主页。
- 个人主页支持微信用户登录测试。
- 个人主页支持通过微信头像选择器和昵称填写组件修改个人资料，并按 OpenID 缓存资料。
- 点击头像进入作者主页，点击图片进入详情页。
- 上传图片到云存储并记录到 `photos` 集合。
- 查看当前用户的上传历史。
- 下载、使用微信原生图片菜单分享、全屏预览图片，并允许作者删除自己的图片。
